# Pocket

A phone-width work tracker. The list starts empty.

Add a task, name it, and move the phase: Evaluate, then Investigate feasibility, then Ready for review. The bar follows that phase. Up, down, and the drag handle change the order. Edit a task to rename it, add key-work lines, or remove it.

What you add is saved in this browser. Another browser, or a cleared site data store, starts empty again.
